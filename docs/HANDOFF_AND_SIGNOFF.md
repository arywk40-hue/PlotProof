# Handoff and sign-off checklist

The agreement is not signing-ready until the owner fills in and accepts the following terms:

- Parties' legal names and authorized signatories.
- Sepolia as the current target network, or an explicit approved redeployment plan to another network.
- Hosting owner for the frontend, backend, database, domain, and monitoring.
- Milestone deadlines and acceptance criteria, including the definition of UI approval.
- Payment milestones.
- Warranty and bug-fix period.
- Source-code ownership and repository access after handoff.
- Credential ownership and rotation process for Pinata JWTs, deployer keys, RPC credentials, and hosting accounts.

Corrected delivery status language:

| Item | Status |
| --- | --- |
| Contract development and testnet deployment | Completed on Sepolia; hosted frontend integration and live transaction proof pending |
| UI enhancement | Implemented baseline; final device and accessibility approval pending |
| Live camera and IPFS evidence upload | Implemented; real-environment integration test pending credential configuration |
| End-to-end workflow testing | Pending recorded live run |
| Production deployment | Pending hosted frontend and backend |
